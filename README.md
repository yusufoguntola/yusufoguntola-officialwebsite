# Yusuf Oguntola

This is my personal official website — a place to share my background, my work, my writing, and resources I've put together to help others learn.

## Sections

- **About** — who I am and how I work
- **Experience** — my career history
- **Learning Resources** — things I've built and shared publicly to help others learn
- **Blog** — my writing on technology leadership, business strategy, and building infrastructure for African markets
- **Press** — interviews and features

## Writing a post

Posts are markdown files in `blog_content/`, with frontmatter for `title`, `date`, `tags` and `excerpt`.

Tables get a header rule and faint row lines by default. To pick a different look, put a marker on its own line directly above the table:

```
{table: bordered}

| Feature | Value |
|:--------|:------|
| ...     | ...   |
```

Available styles, which can be combined (`{table: bordered striped}`): `bordered` (full grid), `borderless` (no rules), `rows` (row lines only — the default), `striped` (zebra rows), `compact` (tighter cells).
